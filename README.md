# LaraBooks -Web Application

A funtional Online Bookstore built using Laravel. This application allows user to browse books and buy it. Admin can manage the book categories and product, also gain overall status.

## Features
- User Authentication
- Search and advacne filter options
- Buy the book using eSewa (Nepali wallet)
- Management of categories and products by Admin
